# .github

Repositório de padrões da organização **IA-Soberana**.

Os arquivos deste repositório são usados como **padrão** por todos os repositórios da organização que não tenham um equivalente próprio:

| Arquivo | Efeito |
| --- | --- |
| `CONTRIBUTING.md` | guia de contribuição exibido em issues e pull requests |
| `pull_request_template.md` | corpo inicial de novos pull requests |

Para sobrescrever um padrão, crie o arquivo correspondente no repositório desejado.

> Este repositório precisa ser público para que o GitHub aplique os padrões em toda a organização.

## Validação automática

As regras descritas no guia são verificadas por workflows mantidos neste repositório, em [`.github/workflows`](https://github.com/IA-Soberana/.github/tree/main/.github/workflows). A seção 5 do `CONTRIBUTING.md` mostra como ativar as validações em um repositório.
